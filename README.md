# BIGSPY AI List Suite

WordPress plugin for directory and listing websites built with [BIGSPY AI Theme WP](https://github.com/bentarofficial/bigspy-ai-theme-wp) in **BIGSPY AI List** mode. It combines three tools in one plugin, each module can be turned on or off:

- **Listing Generator:** create and refresh listings (WooCommerce products) with AI, including SEO metadata, web research and internal links.
- **Post Writer:** write researched blog drafts that link to your listings.
- **Site Insights:** uptime, SSL, technology and performance data for the website behind each listing.

Status: 1.2.1. Install the ZIP from [Releases](https://github.com/bentarofficial/plugin-bigspy-ai-list-suite/releases/latest); later updates arrive in the WordPress dashboard.

Updates will be delivered from GitHub Releases directly in the WordPress dashboard, like the theme.
